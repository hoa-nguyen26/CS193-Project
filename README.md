# Football Match Planner

## Project Goal
Help football fans balance watching matches with classes and schoolwork by identifying scheduling conflicts.

## MVP Scope
- Manually add, edit, and delete matches and busy periods.
- Detect conflicts between matches and personal activities.
- Display upcoming matches chronologically with conflict indicators.
- Save and load schedule data from a file.
- Interact through a terminal menu.

## Future Plans
- Import match schedules from a football API.
- Assign match priorities and suggest which overlapping match to watch.
- Add reminders before selected matches.
